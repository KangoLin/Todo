## 一、产品定位

> **一颗和你一起成长的土豆** —— 把每日时间规划变成养宠物的过程。你遵守计划，它就进化；你完成得越多，它越强大。

- **形态**：桌面端应用（Tauri 2 + React 19 + SQLite）
- **方向**：宠物养成 + 时间规划，**正向激励为主**
- **美术风格**：Q宠大乱斗 / 赛尔号 / 洛克王国式 2D 卡通精灵（暂定）
- **用户**：有自律需求的知识工作者 / 学生
- **在线化**：远期目标。本地核心玩法优先，但数值结构与数据模型需为在线化预留扩展点
- **不做惩罚**：无掉血、无退化、无"宠物死亡"。缺失感（拿不到奖励）而非失去感（被扣掉）

## 二、每日核心循环

```
早晨 ─ 打开土豆：宠物出场打招呼 → 排今天的时间块（播种）
白天 ─ 按时间块执行：点击"开始专注"（番茄钟启动）→ 结束标记完成（浇水）
晚上 ─ 收获：今日复盘 → 宠物按你的表现成长（升级/加属性/进化）
每周 ─ 和上周的自己打擂台（周擂台）
长期 ─ 闯关挑战解锁新内容 + 成就记录
```

## 三、宠物系统

### 3.1 成长线

```
种芽 → 幼苗 → 土豆（基础形态，暂定）
         │
         └─ 第 1 次进化（约 10 级）：按主导属性分支
```

| 主导属性 | 进化形态 | 风格参考 |
|---|---|---|
| 💪 力量 | 壮壮土豆（战斗系） | 结实、戴拳套的肌肉土豆 |
| ⏰ 敏捷 | 风风土豆（速度系） | 有残影、轻盈的疾风土豆 |
| 🧠 专注 | 智智土豆（神秘系） | 冥想打坐、冒星光 |
| 🛡️ 韧性 | 盾盾土豆（堡垒系） | 厚重、石甲土豆 |

- 第 2 次进化（约 20 级）：按当前主导属性分支成稀有形态（雷霆土豆、山岳土豆等）
- 升级时宠物外观细节变化（更大、更亮、多装饰）

### 3.2 四维属性

| 属性 | 来源行为 | 含义 |
|---|---|---|
| 💪 力量 | 完成的时间块数 | 执行力 |
| ⏰ 敏捷 | 按时/提前完成 | 守时与效率 |
| 🧠 专注 | 番茄钟专注时长 | 专注力 |
| 🛡️ 韧性 | 连续 streak 天数 | 坚持力 |

### 3.3 经验数值草案（初版，后续可调）

| 行为 | XP | 备注 |
|---|---|---|
| 完成一个时间块 | 10 | 基础 |
| 按时/提前完成 | +5 敏捷向 | 计划性核心奖励 |
| 延长专注 | +2/15 分钟（封顶计划时长 50%） | 心流补偿，防刷分 |
| 完成一个番茄钟 | +3 专注向 | 专注数据 |
| 当天达成 80% 计划 | +10 韧性向 | streak 累计 |
| 连续 7 天 | 额外大礼包 | 里程碑 |

**关键设计原则**：
- 敏捷（守时）是唯一的大头奖励 → 用户最优策略永远是"按计划完成"
- 延长专注封顶 → 杜绝"30 分钟任务拖 5 小时刷专注"
- 守时判定点是"**按时开始**"：时间块开始时启动番茄钟即守时；拖延的定义是晚开始而非晚结束
- 延长是心流补偿，永远拿不到敏捷权重

### 3.4 战力（简化数值）

玩家可见：**等级 / 战力 / 形态**（三层，一个数字的成长感）。

```
战力 = 等级 × 20 + 力量×2 + 敏捷×1.5 + 专注×1.5 + 韧性×2
```

- 线性简单公式，纯数值累加
- 数据库预留 `power` 字段，上线 PVP 时按战力排序 + 数值比较 + 动画演出，**零重构**
- 玩家不需要理解换算，只感知"战力又涨了"

## 四、经济系统：金币 + 饱食度 + 商城

```
完成时间块 → 获得金币 → 买粮食/皮肤/装饰
    ↑                                │
    └── 喂饱宠物 → 宠物状态好 → 继续战斗
```

### 4.1 金币

| 行为 | 金币 |
|---|---|
| 完成时间块 | +10 |
| 按时/提前完成 | +5 |
| 完成番茄钟 | +3 |
| 当日全部硬承诺完成 | 日结奖金 +50 |
| **硬承诺未完成** | **当日金币奖励减半**（拿不到，不是被扣） |

### 4.2 饱食度

- 范围 0-100，每小时自然消耗
- 饱食度 < 30：宠物表情低落，经验获取打 8 折（成长变慢，**不扣战力**）
- 喂食恢复：商城购买粮食
- **惩罚哲学**："没完成 → 买不起" 而非 "没完成 → 被扣掉"

### 4.3 商城

| 物品 | 效果 | 价格 |
|---|---|---|
| 基础粮 | +30 饱食度 | 10 金币 |
| 高级粮 | +60 饱食度 | 25 金币 |
| 皮肤 | 永久外观 | 金币（价格待定） |
| 装饰 | 永久道具 | 金币 |
| 场景背景 | 永久解锁 | 金币 |

## 五、每日工作流

### 5.1 早晨 · 排计划（播种）

- 打开 App → 宠物出场打招呼 → 今日时间块列表
- 快速添加：**文本 + 起止时间**，回车即建（保留现有交互）
- 硬/软标记：时间块可标 🔒 硬承诺（当天必须完成，敏捷奖励判定基准）或软计划（尽力而为）
- **智能播种（辅助，可开关）**：只给出建议方案（"建议 A：14:00-15:00"），用户点采纳才生效；**系统永不自动分配，用户始终保有手动安排的自由度**

### 5.2 白天 · 执行（浇水）

- 时间块到点 → 顶部提醒"该开始【事项】了"
- 点击 ▶ 开始专注 → 番茄钟启动（默认 25 分钟可调），显示计划时长 vs 已投入
- 完成判定：
  - 提前完成 → 手动"完成"，拿敏捷加成
  - 番茄钟到点完成 → 正常完成
  - 超时仍在投入 → 继续累计专注加成（封顶计划时长 50%）
  - 当天晚些补做 → 只拿基础力量
- 今日进度条（保留现有）：完成/总数，达标线 80%

### 5.3 晚上 · 收获

- 当日回顾面板：完成数、守时情况、专注时长
- 宠物结算动画：经验条上涨 → 升级 → 心情变化
- 未完成的硬承诺顺延至明天（无惩罚，只是待办顺延）

## 六、本地玩法

### 6.1 周擂台（短期节奏）

- 每周日结算：本周四维 vs 上周四维
- 四局制：每项属性单独比，赢一局有胜利动画 + 金币奖励（力量赢 +20 等）
- 结算后清零，周一自动开始新一轮
- 目的：把"周报"变成每周仪式感

### 6.2 闯关挑战（长期目标）

预设关卡，行为里程碑自动判定，通关有结算动画，奖励皮肤/场景/金币：

| 关卡 | 条件 | 奖励 |
|---|---|---|
| 第 1 关 · 发芽 | 累计完成 10 个时间块 | 基础皮肤 |
| 第 2 关 · 扎根 | 连续 3 天达标 | 金币礼包 |
| 第 3 关 · 破土 | 累计专注 5 小时 | 新场景 |
| 第 4 关 · 开花 | 完成 30 个硬承诺 | 稀有装饰 |

- 后期可扩展：节日限定关卡、每周挑战关卡

### 6.3 成就系统（荣誉记录）

- 放在**统计看板（改造为宠物面板）**中作为成就墙
- 记录型成就：如"累计完成 1000 个时间块"、"提前完成 100 次"、"进化 3 次"
- 与闯关（解锁型、有奖励）区分：成就是荣誉记录

## 十、待讨论项（设计中明确标注）

2. **状态值体系与战力/属性的关联**：饱食度等状态值与战力、四维属性的关联设计需单独 brainstorm
3. **美术风格细节**：Q宠大乱斗/赛尔号/洛克王国风格的具体落地（像素 vs 矢量）
4. **商城定价与关卡数值**：初版草案，需数据调优
